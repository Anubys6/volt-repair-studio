# ⚡ Volt Repair Studio
> **Micro-Cirugía de Smartphones & Servicio Técnico a Domicilio**

Sitio web oficial interactivo para **Volt Repair Studio**, especializado en la reparación de iPhone y dispositivos móviles a domicilio en 25 minutos con diagnóstico clínico digital (Dispositivograma) y garantía por escrito.

---

## 🌐 Sitio Web en Vivo (GitHub Pages)
👉 **[Visitar Volt Repair Studio Online](https://anubys6.github.io/volt-repair-studio/)**

---

## 🚀 Características
- **Bot de WhatsApp Interactivo:** Cotizaciones y solicitudes automatizadas de servicio a domicilio.
- **Dispositivograma Clínico:** Inspección visual anatómica del dispositivo inspirada en el odontograma dental.
- **Redes & Reels Studio:** Creador interactivo de publicaciones 1:1 y videos verticales 9:16 para TikTok y Reels.
- **Tablero Kanban de Taller:** CRM ligero para administración de órdenes sin dependencias externas.
- **Animaciones Next-Gen:** Red de partículas eléctricas en Canvas 60fps, 3D tilt en tarjetas y scroll-reveal.

---

## 🛠️ Tecnologías
- HTML5 Semántico
- CSS3 Moderno (Glassmorphism, KaTeX-style cards, CSS Grid, Custom Variables)
- Vanilla JavaScript ES6+
- Canvas API (Partículas eléctricas reactivas)
- Intersection Observer API
- Web Audio API (Efectos de sonido sutiles)
- WhatsApp Click-to-Chat API
